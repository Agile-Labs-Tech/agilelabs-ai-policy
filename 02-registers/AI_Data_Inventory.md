# AI Data Inventory — Full Lifecycle

**AGILE LABS PTE. LTD.** · Rev 1.0 · 14 August 2026 · Owner: ISM · Classification: Internal

> **Evidence for CTM 2025 clauses A.3.4(a), B.9.6, B.9.7.** Governed by [ISMS-27 Section 3](../01-policies/ISMS-27_AI_Data_Governance_and_Handling_Standard.md).
>
> **Finding A.3.4(a) was specifically that the inventory did not cover the lifecycle of the data.** Every row must therefore be complete across all seven stages — collection, input, processing, output, storage, retention, disposal. A row that stops at "processing" does not close the finding.
>
> **These rows are to be merged into the existing Company Data Inventory**, not maintained separately. One inventory, with AI rows in it, is the goal.

## 3. Classification inheritance — worked check

The inheritance rule (ISMS-27 Section 2.3) is the rule most often missed in practice. Trace it once, in writing, so the logic is visible to the auditor:

```
AI-D01  Company source code                    → Confidential
   │
   ├─▶ submitted as input to Cursor
   │
   ▼
AI-D04  Repository context held by vendor      → Confidential   (contains AI-D01)
   │
   ▼
AI-D03  AI-generated code                      → Confidential   (derived from AI-D01)
   │
   ├─▶ must not be pasted into an unsanctioned tool, ticket or chat
   ├─▶ must be reviewed by a second person before merge
   └─▶ stored only where Confidential data is permitted
```

The same logic applies to summaries and embeddings: **reducing volume or changing representation does not reduce classification.**

## Completion guidance

- **Stage 6 has two values** — Company retention and *vendor* retention. Recording only the Company's own retention leaves the lifecycle incomplete, because the data is also sitting with the vendor. This is the specific detail that turns a data inventory into a *lifecycle* inventory.
- **Stage 7 must name a method**, not a policy. "Per ISMS-11" is acceptable only where ISMS-11 names the method for that medium.
- **Rows for data the Company does not hold** (AI-D05, AI-D06) still belong in the inventory. Recording that training data stays in the customer environment, and that production data is prohibited as AI input, is exactly what finding B.9.6 asked for — the auditor named "training data, data input including prompts, data output from AI" and expects all three addressed, including with "not applicable, because…".
